# Phase plan (final, waiting for Omar's "go")

The deadline is about 2026-11-30, which leaves 5 weeks. Every phase ends with code that runs, a test checklist and a push. Security IDs refer to `docs/SECURITY_MAP.md`, and D-numbers refer to `DECISIONS.md`.

Create the public GitHub repo with secret scanning and push protection on (D24).
